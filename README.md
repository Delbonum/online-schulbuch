# TicTacToeAI

Ein Education-Lerntool, das anhand von Tic Tac Toe zwei grundverschiedene Arten von „KI“ erfahrbar macht:

- **Ada** – ein regelbasierter Algorithmus: feste Wenn-dann-Regeln (Pseudocode), die sie Schritt für Schritt abarbeitet. Ada verliert nie.
- **Kai** – eine lernende KI (verstärkendes Lernen): Kai beginnt mit zufälligen Zügen und merkt sich, welche Züge zu Niederlagen geführt haben.

Aktueller Stand: Desktop-Prototyp mit Python/tkinter im Ordner `TicTacToeAI/` (Start: `python TicTacToeAI/main.py`).
Ein Umbau zur Web-Anwendung ist geplant.
